# Memória — Módulo `GRD` (grade de variação)

Regra que vale para **todo** cliente que tem o módulo. O que um cliente específico muda aqui mora em
`clientes/<cliente>/modulos/grd/`.

## Decisões

- [`GRD` é cross-vertical, não é módulo de moda](decision-grd-e-cross-vertical-nao-e-de-moda.md) — polpa de fruta precisa de eixo (sabor × peso) e não é moda; o carimbo "ligado por vertical (varejo de moda)" contradiz o corpo da própria entrada, que já nomeia "sabor" · camada:produto
