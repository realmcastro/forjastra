# docs/arquitetura — racional longo, exemplo, diagrama

Aqui mora o que **não** cabe em `.claude/rules/` (que é normativo e curto) nem no `CLAUDE.md` (que é
panorama com teto duro): exemplo de código, diagrama, comparação de alternativas, racional extenso
de uma decisão.

Decisão em si **não** mora aqui — vira registro `decision` em `memory/`, que é o que os agents leem.
Este diretório é para humano.
